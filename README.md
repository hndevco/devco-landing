# DEVCO — Developers Corporation (Official Landing Page)

> Plataforma web oficial corporativa de **DEVCO (Developers Corporation)**. Desarrollo de software a medida, aplicaciones SaaS, ERPs especializados, sistemas POS de facturación y arquitectura cloud para cualquier industria.

---

## 🚀 Características Principales

- **Diseño Corporativo:** Sistema de diseño institucional basado en los colores de DEVCO (#001350 Azul, #FFC400 Amarillo, #D80027 Rojo).
- **Animaciones Minimalistas:** Red interactiva de partículas matemáticas en Canvas y rotador tipográfico dinámico.
- **Portafolio de Productos Reales:** 10 proyectos en vivo (Salud, Retail, Construcción USA, E-commerce, Logística, Soporte TI y Seguridad).
- **Pipeline DEVCO (En Construcción):** Modal interactivo XL con información de proyectos en desarrollo activo (*TERRANOVA*, *MULTITALLER*, *MEDPHE*, *Entre Otros*).
- **Consola Interactiva:** Simulador y sandbox de código para TypeScript, Python y Go con compilación en vivo.
- **Despacho Directo de Cotizaciones:** Integración del formulario de solicitud técnica directo a hndevco@gmail.com con respaldo local de auditoría.
- **Canal Oficial de WhatsApp:** Acceso directo a WhatsApp oficial (+504 9883-6921).
- **Modo Claro / Modo Oscuro:** Alternador de tema visual con persistencia en \localStorage\.
